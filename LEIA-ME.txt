DTA PERSONAL SOCCER MANAGER — PROTÓTIPO V1

COMO USAR
1. Abra index.html no navegador (computador) ou hospede os arquivos em GitHub Pages para testar no iPad.
2. Acesse a visualização Coordenador e Professor pelo seletor no menu.
3. Teste com dados FICTÍCIOS cadastro de atletas, avaliação inicial, registro de aulas e síntese bimestral.
4. O botão Exportar JSON gera um backup demonstrativo do estado local.

ATENÇÃO
- O protótipo NÃO TEM LOGIN REAL, banco de dados online, sincronização ou autenticação.
- A alternância coordenador/professor é apenas visual, NÃO REPRESENTA CONTROLE SEGURO DE ACESSO.
- Os dados são armazenados no localStorage do navegador. Podem ser perdidos ao limpar os dados do navegador.
- Não inserir dados pessoais reais, de saúde ou de menores.
- Publicar no GitHub Pages NÃO cria o banco de dados nem torna a aplicação apta ao uso real.

PRÓXIMA ETAPA PARA PRODUÇÃO
1. Configurar Supabase Auth (contas individuais de professores e coordenação).
2. Migrar as tabelas atletas, vínculos, avaliações e aulas para PostgreSQL.
3. Criar políticas RLS verificadas e autenticação efetiva.
4. Adicionar auditoria, proteção de dados sensíveis, backup, recuperação, consentimentos e processo LGPD.
5. Integrar exatamente os campos da avaliação bimestral DTA já existente.
6. Testar integralmente com dados fictícios antes de entrar em produção.

PÁGINAS DO MVP
- Painel do coordenador/professor
- Cadastro e histórico de atletas
- Registros de aula
- Avaliação inicial esportiva
- Síntese bimestral demonstrativa
- Exportação JSON
