DTA PERSONAL SOCCER — STUDIO V2
================================

COMO PUBLICAR NO GITHUB PAGES (iPad):
1) Descompacte este ZIP no app Arquivos.
2) Abra o seu repositório DTA-SOCCER-MANEGER no GitHub.
3) Envie TODOS os arquivos da pasta, mantendo a estrutura:
   index.html
   style.css
   app.js
   v2.js
   assets/escudo-dta.jpg
4) Se já existirem arquivos com esses nomes, substitua os arquivos equivalentes.
5) Settings > Pages > Deploy from a branch > main > /(root).
6) Atualize a página depois da publicação.

O QUE FUNCIONA NESTE PROTÓTIPO:
- Alternância simulada entre coordenador e professor
- Cadastro de professores e atletas fictícios
- Avaliações esportivas iniciais
- Planejamento por ciclos individuais
- Registros de sessão e histórico dos atletas
- Síntese bimestral com aprovação demonstrativa
- Exportação dos dados locais em JSON
- Exportação dos registros de sessões em CSV
- Importação de backup JSON (substitui os registros locais)
- Interface adaptada para iPad e celulares

LIMITES IMPORTANTES:
- Não existe login real, e a alternância de perfil NÃO é segurança.
- Dados persistem somente no armazenamento local do mesmo navegador/aparelho.
- Não há sincronização entre professores e coordenador.
- Navegação privada, limpeza do navegador ou troca de aparelho podem apagar os dados locais.
- GitHub Pages hospeda arquivos do site, não mantém bancos de dados privados.
- NÃO INSIRA NOMES, DADOS DE SAÚDE OU INFORMAÇÕES REAIS DOS ATLETAS.
- A ficha gráfica bimestral previamente feita ainda não foi integrada nesta V2.
- O protótipo demonstra fluxo, não está preparado para uso de produção.

PRÓXIMA ETAPA PARA UTILIZAÇÃO REAL:
- Supabase Auth: login individual de professores e coordenador.
- Supabase PostgreSQL: registros persistidos e sincronizados.
- RLS: acesso limitado aos atletas vinculados ao professor.
- Registro de ações e alterações; backups e política de retenção.
- Ficha de segurança dos atletas em módulo de acesso restrito.
- Integração da avaliação bimestral oficial aprovada pela coordenação.
- Testes de segurança, privacidade, usabilidade e consistência antes de uso real.

ATENÇÃO: manter a posse do repositório GitHub não dá acesso automático
às informações de usuários em outros aparelhos. Isso somente será possível
com backend e permissões de coordenação devidamente configurados.
